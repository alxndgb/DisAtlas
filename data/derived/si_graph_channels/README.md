# Graph channel construction counts

Small precomputed tables that cannot be regenerated inside this repository (upstream model runs or benchmark construction). Each line gives the content and the scripts that read the file.

- `SI_graph_channels_counts.tsv`: node and edge counts per channel. Read by: si_graph_channels_schematic.py.
- `edge_weight_range.json`: edge-weight ranges per channel. Read by: si_graph_channels_schematic.py.
