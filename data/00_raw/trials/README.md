# trials

- `trial_triples.parquet` — one row per trial–disease–drug link in the clinical-trial disease–drug network (1,692,970 rows). Columns: `trial_key` (public registry ID — NCT, EudraCT or CTIS — where one exists, otherwise an opaque `TRIAL_B…` key), `disease_id` (MONDO/ORPHA, otherwise opaque `DIS_B…`), `drug_id` (ChEMBL, otherwise opaque `DRUG_B…`), `source_code` (opaque source code; `SRC_0B0DBCC4E9` marks the rare-disease registry source; a disease pair sharing a drug with surviving trials of this source on both diseases is always kept in IxIDN+), `n_drugs_in_trial` (distinct drugs in the trial), `n_excluded_drugs_in_trial` (of those, drugs removed as non-mechanistic), `max_phase` (highest phase 1–4, empty if unknown), `year` (trial year as recorded by the source, empty if unknown). Rows are in the original edge/record order.
