# Audit records from the 10 November 2026 round (superseded)

These files record the per-figure number and table parity checks run against the manuscript draft of 10 November 2026.
They use that draft's figure, table and SI-section numbering (for example Figures S27-S28 and Tables S19-S23, which
the final text no longer has) and refer to items that were later removed from the SI (negative-set realism,
compositionality). They are kept for provenance only; no test reads them.

The current coverage of the final revised manuscript and SI is `release/coverage_table.tsv`, and the current
number registries are `tests/main_text_numbers.tsv` and `tests/si_text_numbers.tsv`.
